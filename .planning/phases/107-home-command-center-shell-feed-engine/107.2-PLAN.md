    3. `export function rankItems(items)` — sort by SEVERITY_RANK asc, then overdueScore desc, then timestamp desc (newest first). Return a new array (do not mutate input).     4. `export function dedupeItems(items)` — group by dedupeKey; when a key repeats, KEEP the instance whose SEVERITY_RANK is lowest (= highest severity), drop the rest. Return deduped array.

    5. `export function rollUpByCategory(items)` — apply the D-05 roll-up: when ≥5 items share the same `category`, keep the first 3 (in already-ranked order) then insert ONE synthetic row { dedupeKey:'rollup:{category}', severity:'medium', category, title:`+${N-3} more ${categoryLabel}`, subtitle:'', deepLink: the category's list route (medium), timestamp:null, isRollup:true }. Categories with <5 items are untouched. (107 seed volume is small — this is exercised mainly for 108, but implement it now.) Provide an internal categoryLabel map (proposal→'Proposals', mrf→'MRFs', etc.).

    6. `export function capItems(items)` — return { visible: items.slice(0,8), rest: items.slice(8,25), overflow: Math.max(0, items.length-25) }. (Collapsed shows 8; expander reveals up to 25; overflow reported for the "Showing 25 of N" line.)

    7. `export async function assembleFeed(user, sources)` — `sources` defaults to `getSourcesForUser(user)` (Task 2). For each source fn: `await source(user)` inside try/catch (a failing source must NOT sink the whole feed — log + skip, but track that at least one failed so the shell can decide to show the error state ONLY when ALL sources fail). Concatenate all items → dedupeItems → rankItems → rollUpByCategory. Then compute and RETURN:
         {
           items,                       // ranked+deduped+rolled (full list, pre-cap)
           cap: capItems(items),        // { visible, rest, overflow }
           total: items.filter(i => !i.isRollup).length,   // real items (rollup rows excluded from the attention count)
           hasCritical: items.some(i => i.severity==='critical'),
           hasHigh: items.some(i => i.severity==='high'),
           allSourcesFailed: boolean,   // true only when every source threw
           fetchedAt: Date.now()
         }
       Empty feed ⇒ total===0 (the shell shows the calm state; distinct from allSourcesFailed which shows the error state).
       Do NOT import onSnapshot. Do NOT register any window function here.
