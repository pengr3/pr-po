## Contracts for 107.3 (consume without re-reading source)

### `assembleFeed(user, sources?)` return shape
`sources` defaults to `getSourcesForUser(user)`. Returns (async):

```js
{
  items,            // Array<FeedItem> — ranked + deduped + rolled-up (FULL list, pre-cap; includes synthetic roll-up rows)
  cap: {            // === capItems(items)
    visible,        // items.slice(0, 8)   — collapsed hero shows these
    rest,           // items.slice(8, 25)  — revealed by "Show all (N)" expander
    overflow        // max(0, items.length - 25) — for "Showing 25 of N …"
  },
  total,            // items.filter(i => !i.isRollup).length — REAL item count; drives the attention one-liner. 0 ⇒ calm empty state
  hasCritical,      // any item severity === 'critical'  → tone the count danger red
  hasHigh,          // any item severity === 'high'       → tone the count amber (when no critical)
  allSourcesFailed, // true ONLY when every source threw → show ERROR state (distinct from total===0 calm state)
  fetchedAt         // Date.now() (ms) — for the "Updated {relTime}" caption
}
```

**State decision for the shell:**
- `allSourcesFailed === true` → error state ("Couldn't load your feed" + Retry).
- else `total === 0` → calm empty state ("You're all caught up").
- else → render `cap.visible`, expander over `cap.rest`, overflow line if `cap.overflow > 0`.

### FeedItem model (D-11)
```js
{
  dedupeKey,    // string — stable dedupe unit, e.g. 'proposal-approval:{id}'
  severity,     // 'critical' | 'high' | 'medium'  (use exported SEVERITY constant)
  icon,         // inline-SVG string (from TYPE_META) — engine is icon-agnostic; roll-up rows carry icon: ''
  title,        // one-line headline
  subtitle,     // supporting context (who / what / amount); '' on roll-up rows
  category,     // taxonomy key: 'proposal' | 'mrf' | …  → CSS class .cc-cat-chip--{category}
  deepLink,     // see kinds below
  timestamp,    // Firestore Timestamp | {seconds} | ISO string | Date | null — for age display + within-tier sort
  overdueScore, // number, higher = more overdue (within-tier tiebreaker); default 0
  isRollup?     // boolean — present & true ONLY on synthetic roll-up rows (exclude from counts; links to category list)
}
```

### Deep-link kinds (D-07) — how 107.3 dispatches a row click
```js
// kind 'route'  → set location.hash = deepLink.value
{ kind: 'route', value: '#/procurement/records' }
// kind 'modal'  → call window[deepLink.handler](deepLink.arg)
{ kind: 'modal', handler: 'homeQueueOpenApproveModal', arg: proposalId }
```
The ONLY modal handler emitted by 107 seeds is `homeQueueOpenApproveModal` (proposal approval row → existing approve/reject modal; reject lives inside that modal). All other seed rows use `route`.

### Ranking / cap / roll-up rules the shell can rely on
- Order: `critical → high → medium`, then `overdueScore` desc, then `timestamp` desc (newest first).
- Dedupe by `dedupeKey`, keeping the highest-severity instance.
- Roll-up: when ≥5 items share a `category`, engine keeps the first 3 then inserts one `{ isRollup:true, title:'+{N-3} more {Label}', severity:'medium', deepLink:<category list route> }` row and drops the rest. (107 seed volume is small; mainly for 108.)

### Seed source registry seam (`getSourcesForUser(user)`)
Returns all three seed functions for any signed-in user (each self-gates); `[]` when no user. **Phase 108 replaces this** with a role → source-set map + per-source severity thresholds.

| Source | dedupeKey prefix | scope | severity | deepLink |
|--------|------------------|-------|----------|----------|
| `sourceProposalsAwaitingApproval` | `proposal-approval:` | approver gate `['super_admin','operations_admin']` + dept scope on `parent_collection` | overdue→critical else high | modal `homeQueueOpenApproveModal` |
| `sourceMyProposalsForRevision` | `proposal-revision:` | `created_by == uid` + `for_revision`, **overdue-only (age > 7d)** | age>14→critical else high | route `#/?tab=proposals` |
| `sourceMyRejectedMRFs` | `mrf-rejected:` | `requestor_name == full_name` + `status=='Rejected'` | high | route `#/procurement/records` |
