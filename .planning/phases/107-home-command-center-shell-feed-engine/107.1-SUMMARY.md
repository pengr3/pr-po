### Notes for 107.3 / 107.4 integrators
- KPI chip markup must include BOTH `.project-scorecard-card` and `.cc-kpi-chip` (the base card supplies white surface/hover; `.cc-kpi-chip` supplies flex sizing + 44px floor + count/label overrides).
- Category-chip element needs both the base `.cc-cat-chip` class AND a `--{domain}` modifier (base supplies pill shape/typography; modifier supplies fill/text). 107 seed sources use only `--proposal` and `--mrf`; the other 8 are pre-declared for Phase 108.
- Severity is set on the row via `.cc-feed-row--{critical|high|medium}`; the tier automatically emphasizes the descendant `.cc-feed-icon` and `.cc-feed-age`.
- `.cc-feed-rollup` is styled as a medium-severity collapsed sub-row (italic muted) — use it for the `+${K} more ${category}` roll-up line.
- Icon color for critical/high rows uses `--danger-dark` / `--warning-dark` (per plan action); medium uses `--primary`.
