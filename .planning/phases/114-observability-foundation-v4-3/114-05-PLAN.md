<objective>
Prove the whole pipeline works locally, then deploy once, then read the live policy back off the
wire.

Localhost is a real test environment here, not a simulation: `app/firebase.js:59-86` routes
`localhost`/`127.0.0.1` to the actual `clmc-procurement-dev` Firebase project, and D-15 deliberately
lets local traffic transmit to Sentry tagged `development`. That means init, scrubbing, breadcrumb
handling and ingest can all be exercised for real before a single production user is involved. What
localhost cannot test is CSP — `http-server` sends no `Content-Security-Policy` header at all, so the
one thing it proves nothing about is the exact thing plan 114-03 changed. Hence the split: everything
verifiable locally is verified locally; CSP is verified against the live response headers after
deploy, and the ingest path through that policy is verified by a human in plan 114-06.

Purpose: shrink the production gate to the only two things production can uniquely prove.
Output: no code changes. One deploy, and a SUMMARY recording what the wire actually said.
</objective>
