## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser (app memory) → Sentry SaaS | Every event and breadcrumb crosses out of the app into a third-party system this organization does not control. This is the phase's primary threat surface. |
| Firestore SDK network layer → Sentry breadcrumbs | The Firestore Listen channel's URLs carry session auth material in their query strings, and Sentry's `fetch`/`xhr` breadcrumb integration records URLs by default |
| DevTools console → `window.__sentryTest` | A permanently-exposed global callable by anyone with the page open |
