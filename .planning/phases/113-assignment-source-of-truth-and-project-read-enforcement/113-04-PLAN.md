| browser → `projects` / `services` list queries | The query shape the client sends is what `firestore.rules` evaluates. A narrowed query is only meaningful because the rule (113-10) will require it; on its own it is a UI-level filter. |
| personnel panel → container document write | The only remaining assignment write. Already gated by the `projects` / `services` update rules, which are personnel-based (projects) or role+assignment based (services). |
