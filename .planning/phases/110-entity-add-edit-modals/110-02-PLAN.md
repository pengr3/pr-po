Extend `app/engagement-create.js` so the existing New Engagement modal can be launched from the Project and Service lists with the type pre-locked, and so a successful create auto-closes the launched modal (D-03/D-04). This is the "Add consolidation" backend: Add Project / Add Service will reuse THIS modal (Plans 05/06 wire the buttons), not a wrapper around the retired inline add-forms.

Two pattern-mapper flags are resolved here:
- **Flag #1 (auto-close gap):** `submitNewEngagement()` currently never closes its host overlay. Purpose: give Plans 05/06 an `openEngagementModal({lockedType})` they can call for Add Project (`'project'`) and Add Service (`'service'`).
Output: modified `app/engagement-create.js` with the locked-type param, the exported launcher, and the auto-close hook. `home.js` is NOT in files_modified.
